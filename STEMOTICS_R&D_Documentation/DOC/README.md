
# STEMOTICS Website & CMS — R&D Documentation

## Project Overview

The objective of this project is to rebuild the existing STEMOTICS website using the MERN stack and develop a user-friendly Content Management System (CMS).

The new website must preserve the original website's content, branding, typography, color scheme, images, page structure, and functionality while introducing a modern, professional, responsive layout.

The CMS must allow non-technical users to manage website content without developer assistance.

## Technology Stack

- Frontend: React.js
- Backend: Node.js
- API: Express.js
- Database: MongoDB
- Authentication: Secure authentication and role-based access
- Media Storage: Cloudinary or equivalent object storage
- Payments: Stripe and Helcim, subject to client confirmation
- Email: SMTP or transactional email service
- SMS: Twilio
- Deployment: Production hosting environment with SSL

## R&D Phases

1. Reference Website Audit & Content Inventory
2. Brand Identity, Typography & Design System
3. CMS Architecture & Admin Dashboard
4. Course, Program & Camp Management
5. Registration, Checkout & Parent Portal
6. Medical Forms, Custom Forms & Communication
7. Gallery, Testimonials, Newsletter & Homepage Content
8. SEO, Performance, Security & Backups
9. MERN Architecture & Database Design
10. Testing, Content Verification & QA
11. Deployment, Training & Handover

## Core Project Rules

- Preserve the original website content exactly.
- Do not miss pages, sections, images, forms, or features.
- Maintain original STEMOTICS branding.
- All client-editable content must be managed through the CMS.
- Preserve existing functionality.
- Ensure responsive behavior.
- Restrict access to sensitive child and medical information.
- Verify all pages against the reference website before launch.

## Completion Criteria

The project is complete when all reference pages and sections have been verified, all required functionality has been implemented, the content matches the reference, and the client can independently manage the website through the CMS.
